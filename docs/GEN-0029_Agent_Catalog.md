# AGENT CATALOG

## Purpose

This document defines the official catalog of engineering agents available
within GENESIS OS.

The Agent Catalog serves as the authoritative registry of agent roles,
capabilities, responsibilities and execution boundaries.

No production agent shall exist outside this catalog.

# Agent Registration Rules

Rule 01

Every agent shall have a globally unique Agent ID.

Rule 02

Every agent shall belong to exactly one primary category.

Rule 03

Capabilities shall be explicitly declared.

Rule 04

Agents shall expose version information.

Rule 05

Deprecated agents shall remain in the catalog until archived.
