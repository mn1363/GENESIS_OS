# PROJECT WORKFLOW

## Purpose

This document defines the official engineering workflow of GENESIS OS.

Every software project managed by GENESIS OS shall follow this workflow.

The workflow guarantees consistency, traceability, repeatability and quality.

-------------------------------------------------------------------------------

# Mission

Transform an engineering request into a validated production artifact using
controlled execution stages.

Every stage produces measurable outputs.

Every stage can be audited.

# Workflow Rules

Rule 01

No stage shall be skipped.

-------------------------------------------------------------------------------

Rule 02

Every stage produces documented outputs.

-------------------------------------------------------------------------------

Rule 03

Validation is mandatory.

-------------------------------------------------------------------------------

Rule 04

Approved artifacts become Project Memory.

-------------------------------------------------------------------------------

Rule 05

Failures return to the previous responsible stage.

-------------------------------------------------------------------------------

Rule 06

Workflow execution shall be deterministic whenever possible.
